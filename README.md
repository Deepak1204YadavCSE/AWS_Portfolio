## ✨ Features

| Feature | Detail |
|---|---|
| **Single file** | Entire site in one `index.html` — no build step, no frameworks |
| **Interactive Terminal** | Real working terminal with 11 commands, history, Tab autocomplete, Ctrl+L |
| **3 Themes** | Green (default) · Amber · Paper — switch via `theme` command or terminal |
| **Responsive** | Mobile-first, stacks cleanly on all screen sizes |
| **Accessibility** | Visible `:focus-visible` outlines, ARIA roles, `aria-live` terminal output |
| **Reduced Motion** | Respects `prefers-reduced-motion` — no animations, instant boot |
| **Scroll Reveal** | Cards animate in on scroll via IntersectionObserver |

---

## 🖥️ Terminal Commands

```
help          list all commands
about         who I am
skills        languages, tools, strengths
projects      3 live projects with links
achievements  hackathons & milestones
contact       github, linkedin, email
whoami        one-liner
theme [green|amber|paper]  switch site theme
train         watch a tiny model train (ML animation)
clear         clear terminal  (Ctrl+L)
sudo          nice try
```

**Keyboard shortcuts inside the terminal:**
- `↑` / `↓` — cycle command history
- `Tab` — autocomplete command name
- `Ctrl+L` — clear screen
